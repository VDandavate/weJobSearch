# Master Profile (Candidate Ground Truth)

> This is the committed blank template (SDD Requirement 1). The real
> `masterProfile.md` lives under the canonical data root
> (`~/Documents/weJobSearch/<username>/`), outside the git work tree; it is
> created by the `init` wizard (Requirement 1b) in this exact same structure and
> filled in offline by the user only.
>
> The resume generator (`generate`, Requirement 3) parses this file and maps
> it into a sanitized template input. Only the fields named below ever reach
> a generated resume, and none of them is a US EEO identifier:
>
>   Contact:  Name, City/State, Email, Phone, LinkedIn, Portfolio
>   Summary / Experience / Skills / Education / Certifications
>
> Work Authorization and any other section are personal data used by other
> commands; they are never mapped into a resume. Do NOT add photo, marital
> status, gender, age, birth date, or a full street address here — even if
> added, the mapping layer drops them and the templates reject them outright.
